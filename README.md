# NavCosmo

Explore. Analyze. Navigate the Moon.

NavCosmo is an interactive lunar landing-site exploration platform built for NASA Space Apps Challenge 2026. This P00 build provides the application foundation, navigation, candidate-site data model, and placeholder visualizations.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Three.js / React Three Fiber / Drei
- React Router
- Lucide React

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Notes

- Candidate sites: Shackleton Crater and Malapert Massif.
- Measurements and analysis values are illustrative placeholders.
- Authentic NASA datasets and the interactive 3D Moon are planned for later milestones.
